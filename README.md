# Fraccionamiento Residencial San Manuel
### Desarrollos Degara • Preventa Exclusiva en Sector La Aurora, Saltillo, Coahuila

Landing page inmobiliaria de ultra lujo diseñada con estándares interactivos de alta gama (Apple-style interactive video scrubbing, carrusel crossfade cinematográfico, simulación financiera en tiempo real y fondos parallax).

---

## 🚀 Estructura del Proyecto

```text
├── index.html          # Código principal de la aplicación web
├── plano-lotes.jpg     # Plano arquitectónico del masterplan y lotificación
├── .gitignore          # Exclusión de archivos temporales del sistema
├── README.md           # Documentación y guía de despliegue
└── img/                # Activos multimedia optimizados
    ├── 1.jpg .. 9.jpg       # Fotografía arquitectónica horizontal (Desktop 16:9)
    ├── 11.jpg .. 99.jpg     # Fotografía arquitectónica vertical (Móvil 9:16)
    ├── video3.mp4           # Video recorrido panorámico para Desktop
    └── video4.mp4           # Video recorrido vertical para Móvil
```

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico y Estructurado**
- **Tailwind CSS (CDN)** para maquetación responsiva moderna
- **JavaScript Nativo (ES6+)** con aceleración por hardware en `requestAnimationFrame` (60 FPS)
- **HTML5 Video Scrubbing Engine**: sincronización bidireccional continua con el scroll (avance y retroceso)
- **Efectos Parallax CSS**: optimizados para Desktop y dispositivos móviles

## 📦 Instrucciones para subir a GitHub

### Opción A: Desde la consola / terminal

1. Abre la terminal dentro de esta carpeta:
   ```bash
   cd "C:\Users\USUARIO\Desktop\sanmanuel-residencial-web"
   ```

2. Inicializa el repositorio y haz tu primer commit:
   ```bash
   git init
   git add .
   git commit -m "feat: landing page San Manuel Residencial - Degara"
   ```

3. Vincula tu repositorio remoto de GitHub (sustituye con la URL de tu repo):
   ```bash
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
   git push -u origin main
   ```

---

### Opción B: Subir directamente desde la web de GitHub

1. En GitHub, crea un nuevo repositorio público o privado (por ejemplo: `san-manuel-residencial`).
2. Haz clic en **"uploading an existing file"**.
3. Arrastra todos los archivos y la carpeta `img` que están dentro de esta carpeta.
4. Haz clic en **"Commit changes"**.

---

## 🌐 Cómo activar GitHub Pages (Web en Vivo Gratis)

Una vez subido el repositorio a GitHub:
1. Ve a la pestaña **Settings** (Configuración) de tu repositorio en GitHub.
2. En el menú lateral izquierdo, selecciona **Pages**.
3. En **Build and deployment > Branch**, selecciona la rama **`main`** y la carpeta **`/(root)`**.
4. Haz clic en **Save**.
5. En 1 minuto tendrás tu enlace público oficial en vivo: `https://TU-USUARIO.github.io/TU-REPOSITORIO/`.
